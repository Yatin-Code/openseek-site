The two forms post to the registry with your session cookie. The key id is the number shown beside the key on the registry keys page; a revocation needs the checkbox ticked. If the server rejects a static form for a missing token, create or revoke from that page instead.

Usage

Usage loads from the registry.

Quota is counted per key per UTC day and not enforced: over-quota keys keep working. This panel reports aggregate counts only. It never shows per-title watch history — the registry keeps per-title-per-day demand counters and no user ids, IPs or histories, and this page stays inside that rule.
