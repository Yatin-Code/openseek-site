OpenSeek

OpenSeek serves scrub-preview thumbnails for video players as JPEG sprite sheets and a WebVTT cue track. A player looks a title up by metadata id and duration, reads the cue that covers the current playback position, and crops one 320×180 tile out of a sheet.

The reference implementation is three Python programs: a generator, a static file server and a registry. Coverage is per title and can be partial, so every lookup reports where coverage ends. New coverage is merged in from players that watch.
